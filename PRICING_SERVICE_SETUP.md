# Free automatic pricing on Windows

No subscriptions, paid pricing API, paid hosting or cloud account are required. Download the package from **Free desktop pricing** in the wine app, extract the ZIP and double-click **Start Wine.exe**. The same app opens in your browser and automatically starts public-retailer price research after inventory uploads. Keep the starter window open while the research runs. No code or terminal commands need to be entered.

The first launch downloads the official pinned Node.js 24.19.0 Windows runtime over HTTPS, verifies its pinned release archive SHA-256, and extracts only node.exe into the app's .runtime folder. Later launches verify the installed runtime hash and reuse it. The local engine binds only to 127.0.0.1, explicitly disables paid search, and stores SQLite inventory/history/jobs under the package's data folder. Browser ranking, journal and imports use the existing app. Keep the same extracted folder for later launches and retain data when updating the application. Closing the engine stops background jobs; restarting resumes the queue.

For a complete Flickinger export select **Complete inventory snapshot** during import. Offers missing from the new file stop appearing as available, while history is retained. Load the supplied Wine Spectator charts once from **Vintage charts**. Subsequent inventory imports keep these assessments. Verified market comparisons and discounts update the rankings as searches finish; the buying table reloads server data every minute while dialogs are closed. Market research shows the queued/completed jobs, retailer coverage and failures.

The public GitHub Pages site and the free desktop app have separate storage. Export an existing engine backup and restore it in the desktop app to retain manual reviews/corrections, or import the original Excel file there. Backup restoration disables source retrieval permissions; review and enable the validated source in Market research afterward. No private inventory, database, secret or personal backup is bundled or published.

Large inventories are queued, not searched all at once. The existing limits remain: at most two concurrent jobs by default, minimum five seconds per merchant request, bounded product-page discovery and 12-hour price-result caching. Only JJ Buckley currently has a live-validated automatic adapter. Other candidates stay inactive pending robots/terms/product/stock checks. The launcher does not bypass blocked websites. Unavailable or uncertain offers do not become fabricated prices or a claim that there is no arbitrage. Median, lowest verified price, package savings, confidence, stock, timestamps and URLs feed the existing market ranking component.

## Reproducing the package

After npm ci and npm run build, run `python3 scripts/package-desktop.py`. The builder requires a Go toolchain and uses no external Go libraries. It cross-compiles desktop/launcher/main.go to a Windows x64 executable and packages only dist (excluding nested download archives), server, src/engine, package.json and the instructions. It leaves user data outside the package. Run npm run build:pages afterward to publish the package in docs/downloads. The compiler may be selected through WINE_GO.

The Windows binary is cross-compiled in this Linux cloud environment. Runtime download verification, service startup and persistent SQLite functionality are tested using the same launcher source compiled for Linux, and the app's desktop browser regression suite. Native Windows execution must be confirmed on the user's PC.
